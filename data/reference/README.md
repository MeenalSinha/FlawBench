# Reference recordings

Place clean reference recordings here (the default `storage.reference_dir`).

Audio files in this directory are ignored by git. Before sharing or committing any recording, confirm
that its licence permits redistribution and that every speaker consented to its use. Record the
source and licence of each recording alongside it (Phase 2 will define the metadata schema).

This directory is read-only input from the application's point of view: FlawBench never writes here.
